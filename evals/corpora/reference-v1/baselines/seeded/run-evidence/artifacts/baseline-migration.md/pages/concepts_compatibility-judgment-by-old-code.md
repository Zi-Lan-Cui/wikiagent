# 以旧代码为准的兼容性判断

在数据库迁移的扩展阶段，判断一项变更是否兼容的核心原则是：**以旧代码的运行能力为基准**。这意味着，任何数据库结构变更（如新增列、新建表）都必须确保在变更执行后，当前已发布的、尚未更新的旧代码版本仍然能够正常运行，不会因为结构变化而出现错误或功能异常。

## 判断基准

兼容性判断的唯一基准是**旧代码的运行能力**。评估一项变更时，需要模拟或验证：当数据库结构已应用该变更，但应用程序代码仍为上一个已发布版本时，所有相关的数据读写操作是否都能成功完成，业务逻辑是否不受影响。

## 应用场景

此原则具体应用于数据库迁移三阶段流程的[[entities/three-phase-migration-process|扩展阶段]]。在该阶段，所有变更必须遵循“只做加法”的规则（例如，新增可空列、创建新表），其目的正是为了满足“以旧代码为准”的兼容性要求，从而保证系统在任何中间状态下的稳定运行。
