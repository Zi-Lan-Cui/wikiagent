# 自动化闸门

自动化闸门是数据库迁移 [[entities/three-phase-migration-process|三阶段迁移流程]] 中，收缩阶段删除操作的前置自动校验机制。其目的是在执行不可逆的删除操作前，通过系统化检查确保安全条件已满足。

## 职责与校验条件

自动化闸门的核心职责是作为收缩阶段的自动化安全关卡。根据当前体系的设计，它需要校验以下前置条件：

1.  **访问计数**：确认目标旧结构（如旧列、旧表）的访问计数已降至零或安全阈值。
2.  **快照存在性**：确认已创建必要的数据快照或备份，以便在出现问题时进行恢复。

## 当前状态

自动化闸门是当前数据库迁移体系中的一个明确缺口。现有流程依赖人工判断和监控指标，尚未实现完全自动化的校验与阻断机制。该机制的缺失是流程性失守可能演变为系统性风险的环节之一。
