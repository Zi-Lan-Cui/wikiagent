# 旧结构访问计数

旧结构访问计数是数据库[[entities/three-phase-migration-process|三阶段迁移流程]]中，收缩阶段用于判断旧结构（如旧列、旧表）是否可以安全删除的一项关键监控指标。其核心作用是提供客观数据，以确认在代码发布后，系统中是否仍有组件在引用旧结构。

## 作用与判断依据

在收缩阶段，团队会发布一个不再引用旧结构的代码版本。此后，需要观察至少一个完整的发布周期。在此期间，通过监控系统观察“旧结构访问计数”这一指标。该指标记录了在特定时间段内，对旧结构的访问请求次数。

判断是否可以删除旧结构的直接依据是：**旧结构访问计数是否归零**。如果计数持续为零，则表明新代码已全面生效且无遗留引用，旧结构可被安全删除。反之，如果计数不为零，则说明仍有组件在访问旧结构，此时删除操作是危险的，必须暂停。

## 与自动化闸门的关系

旧结构访问计数是[[entities/automated-gate|自动化闸门]]校验条件之一。在规划的自动化流程中，闸门会自动检查此项计数以及其他前置条件（如快照存在性），只有当所有条件满足时，才允许执行旧结构的删除操作。这旨在将基于监控指标的判断从人工观察转变为系统化的约束，以避免因流程性失守导致的事故。
