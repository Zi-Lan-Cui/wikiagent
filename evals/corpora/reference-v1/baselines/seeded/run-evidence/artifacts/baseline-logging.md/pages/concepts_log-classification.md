# 日志分类

日志分类是结构化日志规范的核心架构决策，它将日志明确划分为三种类型，并要求通过独立的管道进行处理，以解决线上排障效率低和日志敏感信息泄露问题。

## 分类定义

规范将日志分为以下三类：

1.  **排障日志**：用于线上问题排查。
2.  **审计日志**：用于安全与合规审计。
3.  **指标事件**：用于系统性能与状态监控。

## 处理要求

该分类原则要求这三类日志必须通过**独立的管道**进行处理，这是确保日志可用性与合规性的关键机制。

## 与规范体系的关系

此分类原则是 [[entities/structured-logging-specification|结构化日志规范]] 的顶层分类原则，为后续的字段规范、级别定义、脱敏策略和采样策略提供了分类基础。
