# 评分器定义

本文件定义对编译产物的评分标准：五个阶段的分档维度、确定性校验、以及聚合口径。
标准跨来源通用，不绑定任何具体文档、产物路径或运行结果。评分标准的文字说明写在本
文件，数据文件只承载结构本身。

## 两层判定

| 层 | 内容 | 回答 |
|---|---|---|
| 分档描述 | 十三个维度，每维五档 | 各阶段做得好不好 |
| 确定性校验 | 九条规则 | 产物是否合法，不涉及语义 |

评分可靠性由两点支撑。其一是每个维度强制附带简短理由，先陈述事实、再给分数，缺理由的记录被拒绝。
其二是双模型一致性对照，同一产物分别用主模型与另一族评分模型各评一遍，分歧最大的维度即评判标准存在歧义的信号。

## 五档语义

- **五档 优秀**：断言完全成立之外还见质量，成品在组织、精度、一致性上达到无可改进的典范。
- **四档 周全**：断言完全成立，次要项与边缘也无遗漏、无瑕疵。
- **三档 最小可用**：核心事项齐备、无实质失真，允许存在不影响结论的次要瑕疵，为达标线。
- **二档 不达标**：一处核心事项缺失或实质失真。
- **一档 严重不达标**：多处核心失败，或关键结论错误。

## 各阶段维度

| 阶段 | 维度 |
|---|---|
| 抽取 | 事实一致性；关键内容覆盖度 |
| 检索 | 检索准确性 |
| 分析 | 实体概念识别度；描述溯源一致性；归类准确性；候选关联准确性 |
| 规划 | 决策正确性；拆分粒度合理性；路径命名可读性 |
| 执行 | 页面内容一致性；关键事实保留度；页面间一致性 |

## 判定方法

每个维度写成关于产物的断言，评分时以一到五的整数衡量该断言在多大程度上成立。一个维度只在其判定所依据的输入为该阶段编译时真实可见时才纳入评定。

阶段得分取该阶段各维度分的加权平均，未纳入评定的维度不计入分母。来源总分为各阶段分的加权平均，缺失的阶段不计入分母。

通过以三档为达标线：任一已评维度低于三档，或任一确定性校验不通过，该来源即判为不通过。

当某个维度的判定对象为空集，例如库中无相关页可召回、无候选页可评定关系、或本批仅产出一页，全称断言对空集自动成立，该维度按对应档给满分，不因缺乏比较对象而跳过不评。
