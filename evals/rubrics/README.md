# 评分器定义

本文件定义评分器评分标准，流程分为确定性校验和 rubric 评分两个阶段。

## 确定性校验

确定性校验用于检验 Wiki 页面结构和阶段间产物，确保其满足 Schema 的约束。

## rubric 评分

rubric 评分是基于预定义的评分标准对产物进行打分的过程。通过为每个阶段设置特定的评分为度，并在迭代过程中不断优化评分标准，rubric 评分能够提供一致且可重复的评估结果。

### 评分标准

每个维度分为5级：
- **优秀**：断言完全成立之外还见质量。
- **周全**：断言完全成立，次要项与边缘也无遗漏、无瑕疵。
- **最小可用**：核心事项齐备、无实质失真，允许存在不影响结论的次要瑕疵，为达标线。
- **不达标**：一处核心事项缺失或实质失真。
- **严重不达标**：多处核心失败，或关键结论错误。

### 各阶段评分维度

| 阶段 | 维度 |
|---|---|
| 抽取 | 事实一致性；关键内容覆盖度 |
| 检索 | 检索准确性 |
| 分析 | 实体概念识别度；描述溯源一致性；归类准确性；候选关联准确性 |
| 规划 | 决策正确性；拆分粒度合理性；路径命名可读性 |
| 执行 | 页面内容一致性；关键事实保留度；页面间一致性 |
